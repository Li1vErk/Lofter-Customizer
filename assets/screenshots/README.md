## 录制建议

1. **主视觉优先级最高**：同一页面先录浅色、再切暗色，对比越干净越好；避免录到个人信息（用户名、私信、收藏等），可先切到演示用小号或遮挡处理
2. 录 GIF 时把浏览器窗口宽度固定在 1200–1400px，缩放到 720px 后文字仍可辨认
3. 装饰图演示建议单独录：展示拖拽定位 → 点击触发热区挤压 → emoji 粒子 → 音效提示（音效在 GIF 中不可见，可在描述里说明）
