# 安装说明

## 前置要求

- 浏览器：Microsoft Edge 或 Google Chrome（Chromium 内核，版本 ≥ 88）
- 操作系统：Windows / macOS / Linux 均可

> 扩展仅作用于 LOFTER 网页版（`*.lofter.com`），不影响其他网站。

## 一、商店安装（推荐）

Edge 商店 / Chrome 商店上架后，直接搜索「Lofter Customizer」点击安装即可。

## 二、手动安装（开发者模式）

适用于想第一时间体验新版本、或想自行修改代码的用户。

### 1. 下载扩展文件

任选一种：

- 在仓库页面点击 `Code → Download ZIP`，解压到任意目录
- 或使用 Git：`git clone https://github.com/<你的用户名>/Lofter-Customizer.git`

解压后应能看到 `manifest.json`、`content.js`、`popup.html` 等文件位于**根目录**（不要多套一层文件夹，否则浏览器会提示找不到清单文件）。

### 2. 使用自定义字体（可选）

扩展**不包含字体文件**（三款 CJK 字体合计 15–25MB，会显著拖慢安装与加载）。字体由你安装到操作系统，扩展只负责把字体名写进网页样式：

1. 从 [README 的字体表格](../README.md#-字体与导航) 下载字体并安装到系统
   - Windows：右键字体文件 → 「为所有用户安装」
   - macOS：双击字体文件 → 「安装字体」
2. 打开扩展面板 →「字体」页 → 选中对应预置，字体名会自动填入下方输入框
3. 也可以直接手输系统里已有的任意字体名（如 `PingFang SC`、`微软雅黑`）

没装对应字体时会自动回退到系统默认字体，不会出现排版异常。

### 3. 加载扩展

**Edge**：地址栏输入 `edge://extensions` → 打开左下角「开发人员模式」→ 点击「加载解压缩的扩展」→ 选择扩展所在文件夹。

**Chrome**：地址栏输入 `chrome://extensions` → 打开右上角「开发者模式」→ 点击「加载已解压的扩展程序」→ 选择扩展所在文件夹。

### 4. 生效

打开任意 LOFTER 页面，点击工具栏的扩展图标即可看到设置面板。面板中的改动**实时生效**，无需刷新。

## 三、更新版本

- **商店安装**：浏览器自动更新
- **手动安装**：用新版本文件覆盖原目录，然后回到扩展管理页点击该扩展的「重新加载」按钮

## 四、常见问题

**加载时提示「清单文件缺失或不可读」**
选择目录选错了层级——必须选中**直接包含 `manifest.json`** 的那一层文件夹。

**面板打开但网页没有任何变化**
1. 确认当前页面是 `lofter.com` 域名下的页面
2. 回到扩展管理页确认扩展已启用、且没有报错
3. 尝试硬刷新页面（`Ctrl + F5`）

**某个页面突然失效**
LOFTER 前端使用混淆哈希类名，站点更新可能导致选择器暂时失效。请带上**页面 URL + 控制台输出 + 截图**提 Issue，详见 README 的 FAQ。

**想彻底清除数据**
扩展管理页中「移除」扩展，或在其详情页清理存储数据。所有设置仅存于浏览器本地。
